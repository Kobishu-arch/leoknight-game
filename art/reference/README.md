# Reference art

Concept sprites (AI-made) kept as **models** for drawing new things in the game's own style.
They are not used in the game as they are: thousands of colours, no clean pixel grid, a side-on
camera, single poses and a design that changes from frame to frame. Godot ignores this folder.

| File | Use it as a model for |
|---|---|
| `leo/leo_idle.png`, `leo_gehen.png`, `leo_laufen.png` | idle, walking and a faster run |
| `leo/leo_springen.png` | a jump / hop |
| `leo/leo_angriff.png` | a melee swing with the flute |
| `leo/leo_spielen1-3.png` | the flute-playing poses |
| `leo/leo_special.png` | a special attack (golden wings, notes); also title-screen art |
| `warrior/krieger_idle.png` | the warrior's stance; also title / game-over art |
| `warrior/krieger_gehen.png`, `krieger_angriff.png` | walk and spear attack |
| `warrior/krieger_sprung_angriff.png` | a leap attack |
| `warrior/krieger_rueckansicht.png` | the back view |
| `warrior/krieger_floete.png` | a warrior with a flute (a friendly NPC?) |
| `ui/` | originals of the portraits and item icons; the cleaned-up versions are in `art/ui/` |

The concept palette is in `art/palettes/leoknight_concept.gpl`.
